# 박하영 포트폴리오 사이트

박하영 (Ha-Young Park) — Robotics · AI Researcher 포트폴리오 웹사이트의 원본입니다.

사이트: https://phy0916.github.io/portfolio/

## 고치는 방법

1. `docs/` 안의 Markdown 파일을 고칩니다. 메뉴 순서와 제목은 `mkdocs.yml`의 `nav`에서 바꿉니다.
2. `main` 브랜치에 push하면 GitHub Actions가 사이트를 다시 만들어 올립니다.

## 내 컴퓨터에서 미리 보기

```
pip install -r requirements.txt
mkdocs serve
```

브라우저에서 http://127.0.0.1:8000 을 엽니다.
