> 광운대 로봇게임단 로빛의 예비인턴 과정에서 C 언어와 MCU(AVR) 임베디드를 체계적으로 이수하고, C 게임 프로젝트를 직접 제작·발표했습니다. 로봇 개발자로서의 프로그래밍 기초 체력이 만들어진 시기입니다.

## 🤖 로빛(ROBIT) — 로봇게임단 예비인턴 과정 (2020)

### 공부한 것 ① C 언어 집중 교육 (8일 커리큘럼 이수)

로봇 소프트웨어의 근간인 C를 단계별 커리큘럼으로 학습하고, 매일 과제를 제출했습니다.

| 일차 | 학습 내용 |
|---|---|
| 1\~2일차 | C 기초 문법 — 조건·반복·함수, 형변환, 배열 |
| 3\~4일차 | 동적 할당·다차원 배열 → 포인터 (메모리 모델 이해) |
| 5\~6일차 | 문자열 처리, 구조체 |
| 7\~8일차 | 파일 입출력, 자료구조 기초 — 연결리스트·스택·큐 직접 구현 |

### 공부한 것 ② MCU(AVR) 임베디드 교육

- **1일차** — MCU 기초·회로(basic, circuit)
- **2일차** — GPIO 입출력과 **인터럽트(Interrupt)** 처리, **ADC**(아날로그-디지털 변환), LCD 구동
- 이때 배운 인터럽트·통신 타이밍 개념이 이후 학부 실습("센서 신호 비정상 출력 → 인터럽트 설정 오류·MCU 간 통신 타이밍 문제로 진단·수정")과 KETI의 PLC/PIO 통신 업무로 그대로 이어졌습니다

### 중간 프로젝트 — C 게임 '눈치게임' 직접 제작·발표

"플레이어와 컴퓨터가 **적이 아니라 한 팀**이 되어, 한 음식의 재료를 서로 공유하지 않고 하나씩 고르다가 겹치면 실패"라는 협력형 게임을 C로 구현했습니다.

- **구현 요소** — 시작화면 UI, 난수 생성 기반 컴퓨터 선택 로직(랜덤 함수 직접 구성), 입력 예외처리, 선택 중복 비교처리
- 기획(협력 컨셉 차별화)→구현→시연·발표(Q&A)까지 소프트웨어 프로젝트의 전체 사이클을 처음 완주한 경험

## 🌬️ 동아리 '바람' — 기획부 활동

교내 동아리 '바람'에서 기획부로 활동하며 졸업식 등 행사 기획·운영을 담당했습니다. 행사 일정 관리와 역할 분배를 경험하며, 이후 공모전 팀장 역할(R-biz 등)의 운영 감각을 키웠습니다.
