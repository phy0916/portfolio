## 🥩 부문 ① 민트로봇 × 육가공산업 자동화 (2위 수상작)

### 기획 배경 — 왜 육가공인가

육류 소비량은 꾸준히 증가하는데, 육가공 공장은 다른 식품산업과 달리 자동화가 거의 이뤄지지 않은 3D(Difficult·Dangerous·Dirty) 업종입니다. 현직 노동자 인터뷰(2022.10.15)와 EBS 극한직업 사례를 근거로 "칼을 쓰는 위험 작업 + 중량물 반복 노동 + 영하 작업환경"이라는 문제를 정의했습니다.

### 공정 분석과 적용 시나리오

도축→발골→1차 가공(대분리·소분리)→진공포장→2차 가공→유통포장의 공정 체인을 분석하고, 자동화 가능 지점을 로봇 스펙과 매칭했습니다.

- **진공포장 자동화** — Pal C-SCARA 적용: ±180° 회전(케이블 간섭 없이 360° 도달), 일반 SCARA 대비 2배 이상인 300mm 수직행정으로 포장기계-컨베이어 간 이송 커버. 소분류 제품 중 4kg 미만이 50%·43%라는 실측 중량 데이터를 근거로 가반하중 적합성 검증
- **2차 가공(급속냉동) 자동화** — 식품인증 진공 그리퍼(OnRobot, Payload 2.2kg·자중 0.77kg)로 영하 환경 작업을 대체
- **유통포장 자동화** — 540°/s 고속 동작으로 협동로봇 대비 신선도 유지에 유리한 사이클 타임 확보
- **세척 자동화** — Pal 6-Axis로 고온고압수 작업장 세척을 대체해 근로자 휴식 보장

### 경제성·시장 분석

최저시급 9,160원·일 12시간·월 25일 기준 1인 월 인건비 274.8만원, 로봇 1대당 2명 대체·라인당 8명 가정 시 **월 최소 2,198만원 절감**을 산출했습니다. 2교대 전환 시 공장 가동시간 12→18시간(1.5배)의 생산량 증가 효과, 국내 도축·육가공 사업체 현황과 글로벌 육류시장(1.2조→1.8조 달러) 전망까지 정리하고, 마케팅 전략으로 선점 우위·CSR(구인난 해소)·국내외 EXPO 참가를 제시했습니다. 슬로건: **"For Better Food, By Best Robot"**

## 🧹 부문 ② 트위니 '따르고' × 백화점 청소산업 (동시 출전작)

- **자체 조사 수행** — 백화점 이용 20대 50명 FGI 설문("청소노동자 업무환경을 모르고 있었다" 89%), 현직 청소노동자 인터뷰로 문제 정의(노동강도 상승·열악한 휴게공간·고객-청소 공간 분리)
- **시나리오** — 대상추종 로봇 '따르고'가 ① 충전소 전원 ON → ② 노동자를 추종하며 광고 표시 이동 → ③ 청소 중 알람 모드 → ④ 쓰레기 처리 후 복귀·충전하는 4단계 운영 설계
- **수익 모델** — 로봇+광고판 투자비 4,000만원, 월 광고수익 1,000만원(업체 5곳) 가정 시 손익분기 4.2개월, **연 ROI 285%** 산출. 국내(70개)·일본(190)·중국(8,000)·미국(5,977) 백화점 수 기반 시장 규모 추정
- 청소산업×광고산업 융합이라는 새 가치 제안(이동식 인포데스크 겸용)

## 🌱 리더십 스토리 — 이 대회가 제게 남긴 것

프로젝트 초반, 로봇 비전공 팀원들이 로봇 기술을 몰라 아이디어를 못 내고 참여도가 떨어졌습니다. 저는 광주 국제 IoT가전로봇박람회에 팀원들과 직접 방문해 협동로봇·AMR의 구동 원리와 산업 적용 사례를 눈으로 보여주고, 로봇 기업 부스 인터뷰를 주선해 기술 특징을 구체화했습니다. 이후 공정 단계 기준으로 센서 조사·동작 설계·발표자료 준비로 역할을 재분배하자 팀원 전원이 설계·검증에 참여했고, 그 결과가 2위 수상으로 이어졌습니다. **"리더는 총괄이 아니라 팀원의 눈높이에서 함께 움직이는 사람"** 이라는 원칙을 여기서 얻었습니다.
