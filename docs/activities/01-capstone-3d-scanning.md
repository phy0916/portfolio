# 🎓 캡스톤 설계 — 6DOF 로봇팔 3D 스캐닝

> 🎓 **Depth Camera와 6 DOF Manipulator를 활용한 효율적인 3D Scanning 방안 (졸업작품, 2023)**
>
> 두산 M0609 로봇팔에 Depth Camera를 장착해 3D 스캐닝 시스템을 구현한 졸업작품으로, DH 파라미터 오차 문제를 역기구학 재설계로 해결해 KWIXX 학술대회 우수상을 받은 대표 프로젝트입니다.

## 📋 개요

| | |
|---|---|
| **주제** | Depth Camera + 6 DOF Manipulator 기반 효율적 3D Scanning |
| **수행** | 2023, 졸업작품(캐스톤 설계), 4인 1팀 (팀장) |
| **담당** | 역기구학 해석, ROS 시뮬레이터 제작, 경로 최적화 알고리즘 |
| **수상** | 🏆 KWIXX 학술논문대회 우수상 · 2023 88쉐어챌린지 장려상 |

## 🎯 문제 상황

로봇팔에 Depth Camera를 장착하자 카메라 마디로 인해 **7자유도 구조**가 되었고, 제조사 제공 DH 파라미터와 실측값 간 **15mm 이상의 오차**가 발생해 기존 역기구학 모델이 적용되지 않았습니다. 이 문제로 이후 시스템 구성 단계가 진행되지 않는 병목이 발생했습니다.

## 🔧 해결 과정

- 전공 서적·논문 20편 이상을 5일에 걸쳐 분석, 제조사에 3회 이상 방문해 정보 확보
- 두산 제공 ROS 패키지(Gazebo·Rviz) 시뮬레이터 코드를 처음부터 분석해 좌표계·링크 파라미터 재정의
- **1\~3번 관절은 기하학적 해석, 5번 관절\~카메라는 수치적 해석**을 병행한 하이브리드 역기구학 알고리즘 새로 구성
- 목적지까지의 경로 생성에 패턴이 있음을 발견해 포지션 추정 효율화

## 📈 성과

- 위치 오차 **40% 이상 감소**, 경로 시간 **30% 단축**
- 시뮬레이션과 실제 실험 값이 일치하는 수준 달성
- KWIXX 학술논문대회 우수상, 88쉐어챌린지 장려상, ICROS 2023 학술대회 주저자 발표("임의의 물체를 3D 스캐닝하기 위한 자율적 경로생성 및 이미지 정합 방식에 대한 연구", 총 4명 중 1저자)

## 📚 선행 학습 — M0609 힘제어 Term Project (로봇응용시스템, 2023.06)

캐스톤과 같은 두산 M0609를 대상으로, DART Studio 환경에서 **힘제어(Force Control)를 직접 구현**하는 학기 프로젝트를 수행했습니다. 이 학습이 캐스톤의 제어 기반이 됐습니다.

- **이론 정리** — Torque Control 3방식(위치 기반/모델 기반/혼합), PID 각 게인의 역할(P↑ → Rise Time↓·정상상태 오차↑, I → 정상상태 오차 제거, D → 진동·오버슈팅 억제), Compliance Control(임피던스/힘/혼합 제어) 비교
- **구현 ① 직선 Trajectory** — posx/movel로 5개 웨이포인트 직선 경로 생성 (v=30, a=60)
- **구현 ② 벽 접촉 힘 유지 제어** — get\_tool\_force(DR\_WORLD)로 측정한 외력에 **1차 Low-Pass Filter를 클래스로 직접 구현**(차단주파수 0.3Hz, 샘플링 0.05s, τ=1/2πf으로 계수 유도)해 노이즈 제거 → 목표 접촉력 10N 대비 오차를 PID(Kp 2.5, Ki 0.7, Kd 0.3)로 보상하여 speedl 속도명령으로 출력
- **제어 로직** — 외력 ±4N 데드밴드로 접촉/비접촉을 구분하고, 비접촉 시에는 목표점 ±2mm 허용오차의 위치 제어로 전환하는 하이브리드 구조 — 제어주기 dt=0.05s는 루프 카운터로 실측
- 게인 튜닝 과정에서 I·D항을 켜고 끄며 응답 그래프를 비교 분석 — 실무에서 “이론 게인이 아니라 측정으로 튜닝한다”는 감각을 체득
